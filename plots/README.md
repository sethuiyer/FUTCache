# Plots

Headline visualizations from the FUTCache semantic-cache experiment,
regenerated by `scripts/plot_results.py`. PNGs are checked in so the
plots ship with the repo and reviewers can see them without running
the script.

## Files

The two suffixes distinguish workloads:

- `_english.png`     - 38 queries, 8 topics, English-only paraphrase.
- `_multilingual.png` - 48 queries, 8 topics × 6 languages (en, ja, es,
                         hi, fr, zh).

| Plot | Story |
|---|---|
| `matryoshka_margin_*.png` | `d_max_within` vs `d_min_cross` vs embedding dimension. The "cacheable margin" is negative at every truncation on both workloads: no clean ε threshold separates topics. The cache works because the **insertion order** builds one cluster at a time, before cross-topic points can challenge it. |
| `pareto_memory_vs_error_*.png` | LRU(k) vs FUTCache(ε) Pareto frontier on the same stream. LRU sits at ~99% error regardless of capacity on continuous points; FUTCache curves are strictly below. The starred headline point is 384-d, ε=0.55 on the multilingual corpus: 9 representatives, 81% reuse rate, 100% precision. |
| `precision_vs_coverage_*.png` | The operational metric a production system cares about: P(true reuse \| cache says HIT) on the y-axis against P(cache says HIT) on the x-axis. All four dimensions cluster along the perfect-precision plateau out to ~80% coverage; cross-topic confusion costs precision only beyond ε=0.7. |
| `d_cache_scaling_*.png` | log M(ε) vs log(1/ε) at four dimensions, with linear regression giving empirical D_cache. English-only slopes **decrease with dimension** (0.86 → 0.63); multilingual cluster at 1.0. The two regimes correspond to whether the corpus's semantic structure rewards extra embedding dimensions. |

## Reproducing

```sh
# Generate the input binaries (requires sentence-transformers + Bekko)
python3 scripts/bekko_generate.py    /tmp/bekko_embeddings.bin
python3 scripts/bekko_multilingual.py /tmp/bekko_multi.bin

# Build the C harness
cmake -S . -B build-pack -DFUTCACHE_BUILD_BENCHMARKS=ON
cmake --build build-pack

# Regenerate the plots
python3 scripts/plot_results.py
```

Output goes to `/tmp/futcache_plots/`; copy to `plots/` to refresh.
